# Imagens dos e-mails da LIA TAX

Imagens públicas usadas nos e-mails da LIA: novidades do mês, régua e logos. O GitHub Pages publica cada arquivo num endereço fixo, que o HTML do e-mail usa.

**Endereço:** `https://l-ia-tax.github.io/email-imagens/<pasta>/<arquivo>`

Exemplo: `https://l-ia-tax.github.io/email-imagens/logos/liatax-logo-carbon.png`

## Regras

- **Este repositório é público.** Só entra material de divulgação. Nunca print com dado de cliente, nome de usuário, conversa ou documento de alguém.
- **Imagem publicada não muda nem sai.** E-mails já enviados apontam para ela. Versão nova vai com outro nome.
- **Leve para e-mail:** PNG ou JPG até ~300 KB, gif até ~1 MB, largura de até 2x o tamanho exibido (e-mail tem 680 px).
- **Nome em minúsculas, sem espaço nem acento:** `novidades-2611-trfs.png`.

## Pastas

| Pasta | O que mora |
| --- | --- |
| `logos/` | Logos para e-mail (escuro para fundo claro, branco para fundo escuro) |
| `novidades/AAAA-MM/` | Imagens de cada edição das Novidades da LIA |
| `regua/` | Imagens dos e-mails da régua (teste, assinatura, retenção) |

## Como subir

Pela página do GitHub: abra a pasta, "Add file" → "Upload files", arraste e confirme. Em 1 a 2 minutos a imagem está no ar.
